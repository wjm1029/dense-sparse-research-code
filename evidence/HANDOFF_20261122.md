## 5 模型与任务定义

### Dense6

RGB 是输入，六种输出依次为 `depth=0, normal=1, matte=2, raymap=3, albedo=4, optical_flow=5`。RGB 加六种标签构成用户所说的七模态数据，不是七个输出任务。

LoRA rank32，task router hidden512。prompt 包括：

```text
output: depth
output: surface normal
output: camera raymap
output: albedo
output: optical flow
output: person alpha matte
```

matte 还有 bear、crane、creature、crow、dog、gorilla、horse、lion、monkey、robot 等主体特定 prompt；精确列表读权重 contract，不能自行合并或重排 task table。推理为任务条件预测，通常逐任务 forward，不是一次 forward 同时吐出六张图。

### Sparse

独立 LoRA/router/head，不与 Dense 共享同一份适配器。24 个人体关节，prompt 选择 `output: 2D keypoints` 或 `output: 3D keypoints`。验证时为了比较可分别运行两次，不代表一次同时预测两种。

RGB 输入可使用 VAE encoder；输出直接由坐标 head 产生，**没有 Sparse 输出 VAE decoder**。2D supervision mask 为 in_front AND in_frame，不等于遮挡可见性。3D 为 pelvis/root-relative、相机轴 +X 右/+Y 下/+Z 前，并除以 actor height；不是世界米制坐标，也不能套用 Dense normal 的 flipYZ。

## 6 已完成的训练流程

除 Dense bidirectional 的累计 120k 外，表中的 causal、AR、SF、OPSD 步数均为各阶段自身 optimizer step，不是接在文件名上的累计计数。

| 阶段 | Dense6 | Sparse |
|---|---|---|
| Bidirectional | optical flow 尺度修正为32后重新训练至100k，再加 dispersion 续20k，最终120k | 从官方基座、zero-delta 新 LoRA 和新 head/router 初始化；先单样本 overfit，再 prompt 重构后全量25k |
| Causal | 从120k继承，45,000步 | 从prompt25k继承，22,500步 |
| AR teacher forcing | 从causal继承，43,500步 | 从causal继承，21,750步 |
| Long477 self forcing | 从AR继承，4,800步 | 从AR继承，2,400步 |
| Long477 bounded OPSD | 从SF继承，5,250步，最终完成于10月21日04:14（历史训练记录） | 从SF继承，2,625步，已完成并导出27条验证 |

Dense causal/AR 步数按旧实际阶段目标 ×1.5；Sparse 按对应 Dense 调整后再×0.5。阶段转换继承相应模型参数，新增 history projection 在对应架构转换时按约定初始化；重建阶段优化器，不伪装成跨阶段精确 resume。

短视频通常81 raw →21 latent，AR chunk3。长视频从481帧标签选择前477帧，480×832 → latent `[48,120,30,52]`，40个chunk，每个3 latent。首块对应9 raw帧，其余每块12帧，正好覆盖477帧。

Causal 阶段只限制 RGB 时序 attention；AR 新增目标历史。Teacher forcing 训练用前块 GT，free-running 推理用前块预测；self forcing 训练也用预测历史。最终 OPSD 使用 sink3 + local12 latent 的 bounded KV cache 和绝对位置；历史及 KV 在 chunk 边界 detach。

### Loss

Dense bidir 加 dispersion 后及后续主流程沿用：确定性 `t=0` 的 latent MSE（相应实现以 `-velocity` 对 target）+ `0.001 × router identity` + `0.01 × dispersion`。Dispersion 使用第9个 Transformer block（zero-based 8）的完整时空特征、temperature1、同 prompt 配对，保留 diagonal；四卡 gather 可微。总 loss 可为负，dispersion 饱和或变负不能等同于拟合改善。

Dense OPSD 再加权重1的 EMA teacher latent MSE，teacher decay0.9999，从 latent frame21 开始蒸馏；40个监督块、33个蒸馏块分别归一化。LR2e-5，router2e-6，warmup20，WD0.01，clip1。

Sparse SF 为 coordinate MSE +0.001 router；OPSD 另加权重1的 masked coordinate EMA distillation，decay0.9999、起点latent21。Sparse **没有新增 dispersion loss**。SF LR2e-5/router2e-6；OPSD LR1e-5/router1e-6，warmup20，WD0.01，clip1。

Teacher 在当前 student 生成历史上预测，再用延迟一块的 clean GT prefix replay 替换过去 KV，不将当前块 GT 输入 teacher；teacher 与 student cache 分离。这里是 `t=0` dense/sparse task distillation，不是直接复现上游 diffusion flow distillation。

Dense OPSD 曾在10月19日因 PFS metrics 写入 ENOSPC 中断；10月20日从完整 paired step2200恢复到新的 `_resume_20261020` 输出目录，最终到5250。不是只训到2200，也不是从头重新计5250步。备份只保留最终适配器，没有这份 paired state。

狮子紫色首先存在于原始RGB/albedo，不是 Spectral 色表或模型凭空生成。根因是 actor `.blend` cache 的相对贴图路径在搬动后解析到错误目录；UDIM路径须展开实际tile验证。

长视频1079条中，426条动物视频的 actor color reference 存在断链，约39.48%；不是说所有426条每一帧都显著紫色。原划分1038 train/41 val，移除412 train/14 val后，Dense OPSD使用 **626 train/27 val，共653条人体视频**。错误clip从全部六任务和验证同时移除，原始数据未删除。此前双向、causal/AR、Dense长SF等权重已接触旧数据，后续清理不抹除早期训练影响。

Sparse长视频使用同一653个人体clip，626/27；动物没有该24关节人体schema而被排除。验证是clip-ID holdout，不是actor/action-disjoint泛化。

短视频双向7350的坏数据审计与长视频不是同一分母。历史中有完成的appearance扫描，但最终比例未在本交接中确认；**不能拿长视频39.48%当双向错误数据比例**。

**数值等价性不是无条件通过**：encoder latent最大差0.015625、平均4.09e-8；decoder同一latent输入下输出最大差0.19775、平均0.006536（原始float解码值域）。隔离对照发现整段与分组1×1 `conv2`投影有22/8,985,600个BF16值不同；该差异传播放大。若给缓存decoder完全相同的投影特征，477帧全部571,484,160个像素值与官方decoder逐位一致。按3个latent投影仍有同样差异。

因此缓存状态实现可与官方一致，但当前在线投影实现不能承诺相同输出。没有改官方VAE算子定义或权重，没有训练VAE，也没有把该原型接入正式推理；需先做稳定数值实现及真实dense latent质量验收，不能将随机输入测试的差异直接宣称无感。

下一步顺序：补齐完整推理环境和基座 → 原离线脚本得到最新OPSD基线 → 独立在线入口逐块回调 → 输入encoder与每任务decoder独立缓存/reset → 比较真实case数值/任务指标 → 测含采集、DiT、decoder的首图、首块、稳态延迟及显存。不要把上表两项差值相加当实测端到端提速。
